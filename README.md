# Financial Sample Dashboard

An interactive Microsoft Power BI dashboard for exploring sales performance,
profitability, and financial trends in the Financial Sample data.

## Key performance indicators

- Total Sales: 384.54M
- Total Profit: -100.34M
- Total Units Sold: 2M
- Profit Margin: -26.09%

## Dashboard features

- Year-wise sales trend analysis
- Country-wise sales performance
- Segment-wise sales distribution
- Product-wise profit and loss analysis
- Interactive slicers for Year, Segment, and Country

## Key insight

The dashboard shows negative overall profitability despite substantial sales.
It can help guide further investigation into product performance, customer
segments, country results, and costs.
